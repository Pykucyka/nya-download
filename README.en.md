## Features

- One-tap connection and automatic switch to a working server.
- Add a subscription by link, QR code, manually or with a button on the subscription page.
- Subscriptions update on launch, in the background and with pull to refresh.
- Accurate ping, routing, DNS, per-app selection and transport settings.
- Every server parameter: transport, Reality, fingerprint, FinalMask and full JSON.
- Base64, Xray JSON, sing-box and Clash subscriptions.
- Russian and English interface.

## Getting started

1. Install the app. If the phone asks, allow installs from this source.
2. Open your service's subscription page and tap “Add to nya”, or tap plus in nya and paste the link.
3. Tap the round button and allow the VPN.

On Windows, if you see “Windows protected your PC”, click “More info” and “Run anyway”. For VPN mode, run nya as administrator.
